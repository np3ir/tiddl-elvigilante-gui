# tiddl is bundled INSIDE the app (single binary): flet build reads this
# requirements file and includes the package, so the GUI runs tiddl in-process
# with no separate tiddl.exe. Pinned to the engine commit with the giant-run
# hardening (run-wide 429 circuit breaker, bounded-memory worker pool, opt-in
# --resume checkpoint) AND the fidelity quality cascade (max > high > atmos >
# normal > low, with `atmos` as a -q rung; prefers FLAC over the Atmos AAC that
# the service serves at the LOSSLESS tier), on top of stereo resolution, flexible/
# strict quality policy, playback-manifest validation and the per-album resilience.
# v1.5.3 added the host-safe cooperative stop: Cancel / rate-limit (429) /
# account-flagged (401) now raise click.exceptions.Exit instead of calling
# sys.exit(), so the in-process engine can no longer hard-kill this GUI on a stop
# (see run_tiddl, which catches it and returns the exit code).
# v1.5.4 fixes the HTTP 429 regression on large --artists / high-quality
# runs — all enumeration (playlists, artists, albums, credits) stays on the lenient
# TV client; the 24-bit HI_RES_LOSSLESS tier is fetched per-track only — and makes
# max_tracks_per_session actually stop the run (atomic per-track reservation).
# v1.5.5 fixes the cross-folder "Exists (Alt)" false-skip that dropped
# Dolby Atmos tracks: skip-existing is scoped to each track's own folder, the real
# on-disk name/casing is preserved, and an Atmos request treats Atmos as a distinct
# modality (a same-titled stereo FLAC in another album no longer masks it).
# This pin (main @c5e195a, PR #47) also adds two Windows fixes: the benign
# ProactorEventLoop teardown noise (OSError WinError 10022) is silenced, and the
# standalone cover with an empty [cover.templates] is now saved next to the audio
# as cover.jpg (album/track/playlist) instead of at the download root.
